# RRA-2026-0004 — Functional Decomposition

**Product-design rule:** Function before form. Do not begin with barrel / tote / jug / tank as the answer.

## Desired outcome

The learner can build a storage system that matches one or more real water jobs, uses existing resources where appropriate, keeps materially different jobs separate, and makes maintenance/failure visible.

## Required functions

| Function | Minimum job | What changes by use | Verification |
| --- | --- | --- | --- |
| Contain | Hold required volume without leak/failure | capacity, portability, refill rate | visual inspection; volume calculation |
| Protect | Reduce entry of debris, hands, animals, chemicals or other contamination relevant to the job | potable and produce-contact have higher consequence | inspect closure/openings/location |
| Dispense | Get water out without creating a new contamination or usability problem | potable favors sanitary no-dip handling; livestock/irrigation prioritize reliable flow/access | observe dispensing path and cleanability |
| Clean / inspect | Allow routine access to remove buildup and inspect condition | frequency and method vary by system | maintenance record and condition check |
| Support | Safely carry full water weight and remain stable | large tanks/totes materially increase load/failure consequence | capacity × water-weight estimate + support inspection |
| Separate branches | Keep uses with different consequences from being treated as one identical job | potable, livestock, irrigation, produce-contact, emergency | branch map / labeling |
| Protect from environment | Limit sun/heat/chemical exposure and other site-specific stressors | outdoor trough/tank vs indoor reserve differs | placement audit |
| Rotate / maintain | Prevent forgotten inventory and visible deterioration | emergency reserve has distinct rotation/record needs | dated maintenance plan |
| Verify after concern | Use a targeted check/testing step when a contamination event or quality question changes the decision | specific test depends on the question | targeted verification path |

## Constraints that can make substitution unsafe

### Do not substitute around
- prior toxic chemical, pesticide or petroleum history for potable storage;
- structural support for large/full containers;
- potable-contact suitability when potable use is intended and the material/history cannot be reasonably established;
- a protected dispensing/closure function where routine contamination would undermine the use;
- branch-specific food-safety requirements for produce-contact/postharvest agricultural uses.

### Conditional substitution
A reused vessel can be considered only after the learner can establish enough about prior contents, material/condition, cleanability, closure/openings, placement and intended use to make a responsible job-specific decision.

## Resource classes

### USE WHAT YOU HAVE
- known-history suitable jugs/drums/tanks/troughs already owned;
- existing shaded/protected placement;
- existing shelving/platforms only when load capacity is adequate;
- existing labels/maintenance records;
- existing valves/spigots when suitable and cleanable.

### REUSE / REPURPOSE
- known-history containers for lower-consequence jobs when material/condition/cleanability fit the function;
- non-potable storage clearly segregated and labeled.

### SOURCE LOCALLY
- suitable replacement lids/caps/fittings;
- cleanable spigots/valves;
- stable supports;
- replacement purpose-made containers where existing inventory fails the suitability gate.

### WORTH BUYING
- purpose-made potable storage when prior history/material cannot be established for a drinking-water job;
- sanitary fittings that materially reduce dipping/recontamination;
- structural support or anchoring where capacity/load requires it.

### OPTIONAL UPGRADE
- level indicator;
- protected overflow;
- automatic refill/float valve for appropriate non-potable/livestock systems;
- redundant smaller containers;
- maintenance reminders.

## Minimum viable systems by branch

### Potable everyday / drinking-cooking
Known suitable prior use + cleanable protected closure + sanitary dispensing + protected location + maintenance record.

### Emergency household reserve
Potable-suitable storage + enough calculated capacity + accessible outage dispensing + rotation/fill record + chemical separation + redundancy choice.

### Livestock
Adequate capacity/refill + animal-safe access + cleanability + contamination/algae/manure management + maintenance/testing when concerns warrant.

### Ordinary irrigation / non-food
Capacity + delivery compatibility + contamination consequences appropriate to the actual use + maintenance/access.

### Produce-contact / postharvest
Do not collapse into ordinary irrigation. Use only the approved general distinction in V1 and route crop/commodity-specific thresholds/rules to targeted research when needed.

## Simplest workable system

The learner should be able to select the smallest responsible system that performs the required functions for each chosen job. The product should not reward buying more equipment merely because a larger system looks more capable.

## Upgrade paths

- more capacity;
- more redundancy;
- easier sanitary dispensing;
- automated refill;
- better shade/environment protection;
- easier cleaning access;
- level/condition monitoring;
- better branch separation;
- more durable supports/fittings.

## Verification

A storage system is not proven because it holds water. Verify:
- container condition;
- absence of leaks/failure;
- correct branch/use assignment;
- closure/opening function;
- dispensing path;
- site/support condition;
- maintenance completion;
- specific water-quality questions with appropriate testing when a real concern/event makes that necessary.

# TRANSFER THE PRINCIPLE

A form is only useful when it performs the required functions under the real constraints. Use this same decomposition for food storage, fuel storage, inventory, backup power, tools and household reserves — while keeping water-specific contamination/material rules specific to water.
