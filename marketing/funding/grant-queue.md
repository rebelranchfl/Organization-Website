# Rebel Ranch Ministries / FFN Grant Queue

## Purpose

This file is the only working queue for grant applications and funding
materials from creation through final status. It works the same way as
`marketing/social-media/draft-posts.md`.

A grant application is approved, submitted, rejected, or otherwise
changed only when its own status field says so. Approval alone does not
authorize submission.

The agent must follow `funding-rules.md` and `grant-research.md` before
creating, revising, or submitting any funding material — including
checking the eligibility triage tag on the source `grant-research.md`
entry.

## Workflow Rule

The agent creates drafts, makes requested revisions, checks
`grant-research.md` and `funding-archive.md`, and maintains every status
entry. Brooke only approves, rejects, or corrects, or makes the
legal/strategic calls that are hers alone.

The agent may submit an approved application only when submission has
been separately authorized.

After a grant is submitted, the agent must:

1. Update the entry status in this file to `Submitted`.
2. Copy the final submitted material into `funding-archive.md` with date,
   amount requested, and outcome tracking.

Status values: `Researched`, `Draft`, `Needs edit`, `Approved`,
`Submitted`, `Awarded`, `Declined`.
