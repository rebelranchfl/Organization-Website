# RRA-2026-0001 — Functional Decomposition

## Goal

Teach learners to design water systems by required **functions**, not by starting with product names.

## Core sequence

`SOURCE → ASSESS → TEST → PROTECT → SEPARATE / TREAT → DISINFECT WHEN REQUIRED → STORE → MOVE → CONTROL → VERIFY → MAINTAIN`

Not every scenario needs every function. The learner must determine which functions are required by the source, intended use and actual water condition.

## Function map

| Function | Purpose | Possible forms | Important boundary |
|---|---|---|---|
| Source | Obtain water | well, municipal tap, rain, pond, stored water | Source changes risk profile |
| Assess | Observe known conditions | odor, color, sediment, source history, utility report | Observation does not prove safety |
| Test | Identify unknowns | home screening, targeted test, certified lab | Test method must match decision stakes |
| Protect | Prevent contamination before treatment | wellhead protection, covered storage, clean catchment | Prevention can reduce treatment burden |
| Settle | Let larger solids drop out | settling container/tank | Does not disinfect or remove dissolved contaminants |
| Screen / prefilter | Remove larger debris | cloth, screen, mesh | Not potable-water proof |
| Filter particles | Reduce suspended solids | sand/media filters, cartridges | Performance depends on media and particle size |
| Adsorb selected compounds | Bind certain compounds | activated carbon/appropriate media | Not universal contaminant removal |
| Remove dissolved contaminants | Address specific dissolved substances | RO, ion exchange, specialized media | Must match contaminant and certification/performance data |
| Disinfect / inactivate microbes | Reduce microbial hazard | boiling, chemical disinfection, UV where validated | Does not automatically remove chemicals |
| Store | Hold treated/untreated water | jug, food-safe bucket, drum, tank | Container suitability, cleaning and intended use matter |
| Move | Transfer water | gravity, tubing, hose, pipe, pump | Flow/pressure and material suitability matter |
| Control | Start/stop/regulate flow | valve, float valve, timer, switch | Failure modes matter in automated systems |
| Verify | Confirm outcome | retest, validated indicator, certification, observation where appropriate | Verification method must match claimed result |
| Maintain | Preserve performance | cleaning, replacement, flushing, inspection, retesting | A working system degrades without maintenance |

## Think Like a Rebel questions

1. What is the actual goal?
2. What functions must occur for that goal to be met?
3. Which functions are already handled by the source/system?
4. Which functions remain unknown?
5. What can be verified cheaply before buying anything?
6. What materials/resources are already available?
7. Which substitutions are safe and functionally adequate?
8. Which components are worth buying because safety/performance depends on them?
9. How will the learner know the system worked?
10. What fails if power, replacement parts, pressure or the primary source disappears?

## Resource categories

### USE WHAT YOU HAVE

Use when the existing item safely performs the required function.

Examples of forms that may qualify depending on intended use:
- existing clean containers for non-potable collection/storage;
- existing food-safe containers for appropriate water storage;
- existing hose/tubing for compatible non-potable distribution;
- gravity/head height already available on the property;
- existing roof/catchment surfaces for a rainwater learning path where suitable.

### REUSE / REPURPOSE

Reuse is encouraged only when prior contents, material compatibility, cleanliness and intended use are acceptable.

A container is a **form** of the storage function; it is not automatically suitable for drinking water merely because it holds liquid.

### SOURCE LOCALLY

Potential locally available forms:
- sand/gravel for approved demonstration or prefiltration roles;
- locally available containers;
- common plumbing/tubing hardware;
- structural stands/platform materials;
- simple valves/floats.

Local availability never overrides required material safety or treatment performance.

### WORTH BUYING

Purchase is justified when validated performance, safety, measurement accuracy or reliability matters.

Likely categories:
- appropriate water tests/lab analysis;
- certified treatment components when needed for human potable water;
- UV equipment where microbiological disinfection is required and research/standards support the use;
- specialized contaminant-removal media;
- food-safe storage when existing containers are unsuitable;
- reliable valves/floats/pumps where failure could cause flooding, animal water loss or unsafe operation.

### OPTIONAL UPGRADE

Convenience/performance upgrades may include:
- larger storage;
- automated controls;
- pump instead of gravity;
- level indicators;
- easier cleaning/drain points;
- redundant supply;
- monitoring/retest reminders.

### DO NOT SUBSTITUTE

Do not replace a required safety/performance function with an improvised component merely because it looks similar.

Examples:
- a demonstration sand/charcoal filter is not a substitute for verified potable-water treatment;
- an unknown container is not a substitute for suitable drinking-water storage;
- a generic light source is not a substitute for validated UV disinfection equipment;
- taste improvement is not proof of contaminant removal;
- clear appearance is not proof of microbiological safety.

## Minimum viable systems by scenario

### Rural well / household drinking water

Minimum responsible architecture:

`well source → test/diagnose → required treatment jobs based on results → point-of-use or whole-system choice → safe storage/delivery → verification → maintenance/retesting`

### Farm animal watering

`source → intended animal-use quality check → debris/treatment as appropriate → storage → gravity/pump → line → float/control → inspection/cleaning`

### Rain-fed chicken watering

`catchment → debris exclusion / first-stage management as appropriate → storage → gravity or pump → line → float/nipple/cup control → cleaning/inspection`

This is a distribution/automation system; it must not be presented as a human potable-water treatment system.

### Pond emergency backup

`pond source → source-risk assessment → pre-treatment as appropriate → treatment/disinfection matched to intended use → safe storage → verification`

If chemical/toxin contamination is possible or unknown, simple boiling/filtration/disinfection cannot be assumed sufficient.

## Scale translation

The same functions can scale:

- 1-gallon jug = small storage;
- 5-gallon bucket = larger portable storage/distribution;
- 55-gallon food-safe drum = bulk storage/distribution;
- fixed tank = higher-capacity storage.

The **function stays the same; the engineering constraints change**: weight, support, cleaning, outlet height, pressure/head, fittings, overflow, material safety and maintenance.

## Transfer the principle

The learner should leave able to apply the same mental model elsewhere:

- shelter: contain / protect / ventilate / drain;
- irrigation: source / store / move / control / verify;
- business process: input / transform / control / measure / improve;
- family budget: income / allocate / control / monitor / adjust.

**Function before form is a general problem-solving skill, not a water-only lesson.**
