# FFN Church / Rebel Ranch Ministries — Donations Received

## Purpose

Tracks actual donations received from businesses and individuals so a
donation acknowledgment letter can be generated and sent, and so nothing
gets missed. Managed from the marketing dashboard's "Donations Received"
tab — add an entry when something comes in, and use "Generate letter" to
get ready-to-send acknowledgment text.

This is a different file from `outreach-queue.md` (which tracks asks
before a gift happens) and `funding-archive.md` (which tracks formal
grant submissions/outcomes) — this file is only for gifts actually
received.

Format for the dashboard to read/write, one line per donation:
`- [ ] Donor Name :: Date: YYYY-MM-DD :: Type: Cash/In-kind :: Amount: text :: Category: text :: Contact: text :: LetterSent: Yes/No :: Notes: text`
Check the box once the acknowledgment letter has actually been sent.
