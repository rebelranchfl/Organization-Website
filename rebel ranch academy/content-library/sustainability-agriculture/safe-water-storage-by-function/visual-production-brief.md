# RRA-2026-0004 — Visual Production Brief

**Status:** Product Design brief. Visual Production is not authorized until owner Product Review approval.

## Visual direction

Prestigious, polished Rebel Ranch Academy learning experience. Midnight/deep navy, antique gold accents, warm cream/paper learning surfaces, dark readable text on light surfaces. Use the approved Academy identity and shared rules. No decorative pill-shaped labels. Full pill/capsule shapes are reserved for real clickable controls.

## Primary visual principle

**Show the learner the physical idea before asking them to study the technical system.**

Use familiar container scenes first; technical diagrams/cutaways are deeper teaching layers.

## Required explanatory visuals

1. **Container lineup / Function Before Form opener**
   - jug, bucket, barrel, tote, tank, trough;
   - visually communicates that the forms differ but the job decides suitability.

2. **Prior-use history decision visual**
   - known food/water history;
   - unknown history;
   - toxic chemical/pesticide/petroleum history;
   - must visibly branch by intended use rather than present one universal answer.

3. **Container anatomy cutaway**
   - lid/closure;
   - fill opening;
   - vent where applicable;
   - outlet/spigot/valve;
   - cleaning access;
   - base/support;
   - label/date;
   - sun/heat exposure;
   - nearby contamination paths;
   - overflow/drainage where relevant.

4. **Dispensing comparison**
   - protected pour/spigot vs open dipping contact;
   - plain visual explanation before technical evidence.

5. **Multi-use branch map**
   - shared source/fill point;
   - parallel branches for every learner-selected use;
   - assigned real learner containers;
   - branch-specific corrections;
   - shared vs non-shareable functions.

6. **Capacity / weight / redundancy comparison**
   - one large container vs several smaller containers;
   - approximate full-water weight;
   - portability / single-point-of-failure tradeoff;
   - no fear framing.

7. **Maintenance loop**
   - Fill → Label → Inspect → Clean → Maintain/Rotate → Verify after concern → Correct.

8. **Personalized My Water Storage Plan**
   - visual system map built from learner answers;
   - branch cards/maps must reflect actual learner inventory and selected uses;
   - print/offline view must preserve the plan rather than become a blank worksheet.

## Interaction requirements

- intended uses must be multi-select;
- learner may add multiple containers;
- one container may classify differently by branch;
- hard exclusion / correction / verify-first outcomes must be visually distinct without relying only on color;
- changing an answer updates dependent outputs where practical;
- every deeper route works and preserves state;
- no dead links / 404s;
- every clickable-looking pill must actually click; non-clickable statuses must not use pill shapes.

## Language depth

Default: Plain.  
Optional: Everyday Detail → Technical → Evidence/Sources.

Technical terms may appear only after the learner understands the ordinary-language idea.

## Targeted safety only

Use short in-context warnings for material immediate hazards:
- prior toxic chemical/pesticide/petroleum vessels are not potable reuse candidates;
- large full containers create substantial weight/support risk;
- produce-contact/postharvest uses require stronger specific evidence than ordinary irrigation.

Do not add repetitive generic legal/compliance disclaimer boxes.

## Final Product QA requirements for Visual Production

The owner-review release candidate must prove:
- 3+ simultaneous use selections persist into the final plan;
- multiple containers persist and branch correctly;
- two materially different test profiles produce materially different plans;
- every depth link/control works with zero 404s;
- state survives normal deeper navigation;
- actual explanatory visuals exist, not styled prose substituting for diagrams/cutaways;
- mobile/print behavior is usable;
- the preview manifest points to the exact tested release candidate.
