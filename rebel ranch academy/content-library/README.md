# Rebel Ranch Academy Content Library

This folder is the permanent working and release library for Rebel Ranch Academy learning products.

Each Academy idea becomes its own project folder under the correct learning area. Research, source links, drafts, pricing, owner feedback, QA, and final materials stay with that project for its full life cycle.

## Learning-area folders

```text
content-library/
├── _templates/
├── personal-capability/
├── communication-emotional-intelligence/
├── money-financial-life/
├── business-work-skills/
├── leadership-community/
└── sustainability-agriculture/
```

Use the current public Program Hub learning-area names unless a newer owner-approved standard replaces them.

## Standard project folder

Example:

```text
sustainability-agriculture/
└── RRA-2026-0001-purifying-water-natural-materials/
    ├── project.json
    ├── context-review.md
    ├── concept.md
    ├── research.md
    ├── sources.md
    ├── content-outline.md
    ├── master-content.md
    ├── pricing.md
    ├── qa-review.md
    ├── owner-review.md
    ├── illustrations/
    ├── activities/
    ├── working-files/
    └── final/
```

Do not scatter one project's source research, pricing, drafts, or final files across unrelated repo folders.

## Permanent record rule

GitHub is the permanent source of truth for Academy content-production records. Temporary AI workspaces, chat memory, local scratch files, and dashboard caches are not substitutes for the project folder.

## Owner approval rule

Nothing in this library is automatically public simply because it exists or because an agent completed it. The project's `project.json` and `owner-review.md` must show owner approval before any release workflow begins.
