# Rebel Ranch Ministries / FFN Funding Archive

## Purpose

This file tracks every grant application and funding material actually
submitted, so the agent does not contradict a previous submission, reuse
narrative language inconsistently, or lose track of outcomes.

This is the source of truth for submission history and outcomes.
`grant-queue.md` remains the only working queue — approved-but-unsubmitted
entries stay there, not here.

The agent alone maintains this archive after an authorized submission
goes out. Brooke only approves, rejects, corrects, or supplies judgment
when needed.

---

## Reuse Rules

Do not reuse narrative language between grant applications without
checking it still matches current program status (especially Rebel Ranch
Academy, which is still being built).

Do not submit conflicting figures, claims, or program descriptions to
different funders without checking this archive first.

Track outcomes (awarded/declined) here so future research can prioritize
funders who have already said yes.
