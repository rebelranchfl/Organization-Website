# Rebel Ranch Ministries Draft Posts

## Purpose

This file is the only working queue for social media posts from creation through final status.

A post is approved, posted, rejected, or otherwise changed only when its own status field says so. Approval alone does not authorize scheduling or posting.

The agent must follow:

- `brand-rules.md`
- `content-calendar.md`
- `group-rules.md`

before creating, revising, scheduling, or posting any content.

## Workflow Rule

This file is the working queue for Rebel Ranch social media posts.

The agent creates drafts, makes requested revisions, checks supporting records, finds approved posts, and maintains every status and archive entry. Brooke only approves, rejects, or corrects. Brooke does not manually copy or move posts or maintain another tracker.

The agent should search this file for posts marked:

`Status: Approved`

Approved posts stay in this file until they are scheduled, posted, rejected, or revised.

Before using an approved post, the agent must check:

- `brand-rules.md`
- `content-calendar.md`
- `group-rules.md`
- `image-library.md`
- `posted-archive.md`

The agent may schedule or post an approved post only when scheduling or posting has been separately authorized.

After a post is posted, the agent must:

1. Update the post status in this file to `Posted`.
2. Copy the final live version into `posted-archive.md`.
3. Add the posted date, destination, posted link, image used, and reuse timing to `posted-archive.md`.

Do not create or use an `approved-posts.md` file or any other duplicate working queue. Approval is recorded on the original post in this file, while `posted-archive.md` alone handles posting history, reuse timing, and frequency tracking.
