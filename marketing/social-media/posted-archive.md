# Rebel Ranch Ministries Posted Archive

## Purpose

This file tracks what has already been posted so the agent does not repeat the same content too often, overuse one program, or blast the same post across multiple places.

This is the source of truth for posting history and frequency.

Before posting anything new, the agent must check this archive.

The agent alone maintains this archive after an authorized post goes live. Brooke does not copy posts, move posts, or maintain a duplicate posting-history or frequency tracker. Brooke only approves, rejects, corrects, or supplies judgment when needed.

`draft-posts.md` remains the only working queue. Do not create or use `approved-posts.md`.

---

## Reuse Rules

Do not reuse the same exact post text unless Brooke approves it.

Do not post the same content bucket too many times in one week.

Do not post donation asks back-to-back unless there is a real current need.

Do not repost the same topic into multiple groups without adjusting the wording for the group.

Group posts should feel local and conversational, not copied and blasted.
