# Build Your Water System — Water Profile

**Purpose:** Define the learner's real situation before treatment or product selection.

## 1. Source

Select/record:
- municipal/city;
- private well;
- rainwater;
- pond/lake/creek/surface water;
- stored water;
- mixed/multiple;
- unknown/other.

## 2. Intended use

Treat each materially different use as its own requirements path:
- drinking;
- cooking;
- household/general cleaning;
- animals/livestock/poultry;
- irrigation/garden;
- emergency backup;
- educational demonstration.

## 3. What is known?

Record only evidence/observations actually available:
- utility report;
- laboratory/certified test;
- targeted test;
- home screening;
- visible sediment;
- taste/odor/color observations;
- source history;
- recent flooding, repair, disuse, contamination event, or change.

## 4. What is assumed?

List beliefs that have not been verified.

## 5. What is unknown that could change the solution?

If an unknown materially changes potable-water treatment, the next action is to test/learn it rather than prescribe a device.

## 6. Setting and constraints

Record:
- renter/homeowner/rural/farm/homestead/off-grid/emergency;
- plumbing modification allowed?;
- electricity available?;
- scale/volume needed;
- portability needed?;
- counter/installation space;
- existing storage;
- gravity/elevation available;
- existing pump/plumbing;
- maintenance tolerance;
- automation goal;
- budget priority.

## 7. Priority ranking

Rank what matters most:
- treatment confidence;
- lowest upfront cost;
- lowest ongoing cost;
- least maintenance;
- highest independence;
- lowest power use;
- fastest setup;
- portability;
- automation;
- fewest replacement consumables.

## 8. First decision

Complete this sentence:

**Before I buy or build anything, the next thing I need to know/do is:** ____________________

## Stop rule

For unknown water intended for human drinking, do not jump from this worksheet directly to a potable-treatment prescription when critical water-quality information is missing.
