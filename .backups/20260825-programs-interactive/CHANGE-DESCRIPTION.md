# Programs Hub interactive experience — change description

**Date:** 2026-08-25
**AI-Agent:** ChatGPT/Codex
**Session:** RRM Programs Page & Agricultural Program Architecture

## Owner-approved direction

Rebel Ranch Ministries is digital-experience-first. The Programs Hub must use an intent-driven **“I want to…”** interaction model instead of forcing visitors through six long program essays.

## Authorized target

- `programs.html`

## Intended change

- Turn the existing “Find Your Program” cards into true intent selectors.
- Make the page respond to the visitor’s selection with a focused recommendation, direct next actions, relevant connected paths, and the matching program details.
- Keep unrelated program-detail sections out of the way until selected.
- Preserve a real “view all programs” option for visitors who want to browse.
- Replace placeholder-like “happening now” copy with clickable routes into currently available RRM experiences and media rather than pretending dynamic feeds exist before they do.
- Preserve the approved RRM visual system, mobile behavior, program boundaries, shared shell, and all existing live destinations.
- Do not add a framework, backend, database, new program page, or future functionality that is not currently live.
