# Rebel Ranch Ministries Facebook Group Rules Tracker

## Purpose

This file tells the marketing agent where Rebel Ranch content can be posted, what each group allows, and what rules must be checked before posting.

No Facebook group post should be drafted, scheduled, or posted without checking this file first.

The agent owns this review and tracking work. Brooke does not manually inspect Facebook groups, copy rules, or maintain a separate group tracker. Brooke only resolves a judgment call when the agent identifies one that cannot be decided from the group's published guidance.

---

## Master Group Posting Rules

Before any group is used, the agent must use available browser access to review:

- the About section
- the Rules section
- Featured posts
- pinned posts
- admin announcements or other admin guidance

The agent must then check:

- Is nonprofit posting allowed?
- Are donation posts allowed?
- Are business/program posts allowed?
- Are local business posts allowed?
- Are links allowed?
- Are promo posts only allowed on certain days?
- Does the post need to sound like a personal shout-out instead of an organization post?
- Has Rebel Ranch posted in this group recently?
- Does this post fit the group, or does it feel like spam?

The agent records the group link, findings, review date, and source locations in this file. If browser access is unavailable or a required section cannot be viewed, keep the group status `Needs review` and do not draft for, schedule to, or post in that group.

Owner-approved no-published-restriction rule (2026-08-16): after the agent completes the visible About, Rules, Featured, pinned, and admin-guidance review, an in-scope local group may be marked `Approved` when no published rule prohibits or limits posting, promotion, nonprofit content, or relevant links. Absence of a restriction does not override a written rule, admin guidance, required pre-approval, an incompatible group purpose, an unresolved group identity, or the Florida-only boundary for Newberry groups. Posts must remain locally relevant, non-repetitive, and consistent with `posted-archive.md`.

The agent must not post, message an admin, request to join, join, leave, or change group or Facebook settings unless that exact action is separately authorized.

`posted-archive.md` is the only source of truth for where and when content was posted. Do not maintain posting history or frequency in this file.

---

## Agent Review Procedure

1. The agent opens the group using available browser access.
2. The agent confirms the group name and saves its direct link.
3. The agent reads the About section, Rules section, Featured posts, pinned posts, and admin guidance.
4. The agent records what is allowed, prohibited, limited by day or frequency, and whether links or promotional content are permitted.
5. The agent records the review date and the sections used as evidence.
6. The agent sets the status to `Approved` when published guidance allows the intended use or when the owner-approved no-published-restriction rule applies. A group stays `Needs review` when access, identity, location, purpose, or a required section remains unresolved; it becomes `Do not use` when published guidance or scope excludes it.
7. Before each later group post, the agent rechecks the visible guidance and `posted-archive.md` for recent use.
