# Rebel Ranch Ministries Outreach Queue

## Purpose

This file is the only working queue for outreach messages from creation
through final status. It works the same way as
`marketing/social-media/draft-posts.md`.

A message is approved, sent, rejected, or otherwise changed only when its
own status field says so. Approval alone does not authorize sending.

The agent must follow `partner-rules.md` and `local-landscape.md` before
creating, revising, or sending any outreach.

## Workflow Rule

The agent creates drafts, makes requested revisions, checks
`local-landscape.md` and `outreach-archive.md`, and maintains every status
entry. Brooke only approves, rejects, or corrects.

The agent may send an approved message only when sending has been
separately authorized.

After a message is sent, the agent must:

1. Update the entry status in this file to `Sent`.
2. Copy the final sent message into `outreach-archive.md` with contact
   method, date, and target details.

Status values: `Researched`, `Draft`, `Needs edit`, `Approved`, `Sent`,
`Rejected`.
