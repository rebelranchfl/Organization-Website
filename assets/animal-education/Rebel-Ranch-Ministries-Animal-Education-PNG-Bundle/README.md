# Rebel Ranch Ministries Animal Education PNG Bundle

This bundle contains 34 original PNG images recovered from the referenced ChatGPT conversation. The image pixels were not edited. Files were given descriptive names and organized into topic folders so the series can be downloaded, shared, and managed easily.

## Folder guide

1. `01_Pig_Series` — regenerative farming plus the complete seven-image pig education series (8 PNGs).
2. `02_Chicken_Series` — the complete seven-image chicken education series (7 PNGs).
3. `03_Earlier_Chicken_Concepts` — four earlier chicken-series concepts (4 PNGs).
4. `04_Rabbit_Series` — the complete five-image rabbit education series (5 PNGs).
5. `05_Nutrition_And_Food_Value_Series` — the complete six-image nutrition and food-value series (6 PNGs).
6. `06_Shared_Soil_And_Manure` — the shared N-P-K/manure comparison graphic (1 PNG).
7. `07_Guides_And_Archive` — the overview collage and two visual folder guides (3 PNGs).

Total: 34 PNG files.

## Notes

- Generated attachments had file identifiers rather than useful filenames, so descriptive filenames were assigned from each graphic's visible title.
- `03_Earlier_Chicken_Concepts` contains the four images that actually existed in the conversation. Those graphics are visibly numbered 1–4 of a planned five-part set; no fifth PNG attachment was present.
- `IMAGE-INVENTORY.csv` lists every PNG, its source identifier, dimensions, size, and SHA-256 verification value.
- The source attachments were copied without alteration. Every organized copy was hash-checked against its recovered source.
