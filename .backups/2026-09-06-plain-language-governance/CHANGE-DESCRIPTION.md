# Change Description — Plain-Language Governance Update

Date: 2026-09-06

Owner-authorized repository governance change.

File intended for change:

- `/AGENTS.md`

Purpose:

Strengthen the repository-wide communication rule so every AI agent communicates with the owner in plain language in every subject area — technical or non-technical — as if the owner has no prior subject-matter knowledge.

Required behavior to add:

1. Explain all specialized terms immediately in ordinary language.
2. Do not assume technical, legal, financial, educational, operational, regulatory, scientific, or other subject-matter knowledge.
3. Explain what something means before discussing what to do with it.
4. Prefer concrete everyday examples when they improve understanding.
5. Do not substitute jargon, acronyms, raw system language, or specialist shorthand for explanation.
6. When showing code, logs, legal/regulatory language, financial terms, or system output, first translate the practical meaning in plain language.
7. Continue to preserve factual precision; plain language must not mean oversimplifying away important facts.

No website code, program files, databases, deployments, branding, or live behavior are authorized to change in this batch.
