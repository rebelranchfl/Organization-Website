# Product Recommendation Scorecard — RRA-2026-0011: What Is Emotional Intelligence?

Per ACADEMY-PRODUCT-PHASE-WORKFLOW-EXTENSION.md Section 4. This is a recommendation to the owner, not an approval.

| Criterion | Assessment |
|---|---|
| Demonstrated audience interest | Not directly measured (no analytics live yet on the Academy hub); inferred from the sheer volume of free EI content that exists, which signals durable public interest even without RRA-specific data. |
| Problem urgency/importance | Moderate-high: reacting badly under emotion is a near-universal, recurring problem, not a rare edge case. |
| Approved research depth | Solid for an introductory piece: 10 sources, real disagreement documented, one specific technique with direct evidence. Not deep enough for an assessment tool or clinical content, and this product doesn't attempt either. |
| Historical/pattern value | Meaningful — the century-long relabeling pattern is itself a useful teaching hook (Thorndike → Gardner → Salovey/Mayer → Goleman → RULER). |
| Resource-spectrum value | High: zero cost/equipment barrier, works for any household. |
| Market saturation | High saturation, low differentiation in existing free content (see Market & Gap Research). |
| Unmet need/gap | Real: the honest-and-actionable combination is genuinely missing from what's freely available. |
| RRA differentiation | Clear and specific: cited disagreement + one named, evidenced technique + explicit "where the analogy stops" discipline. |
| Knowledge Compression Value | Real — compresses 4 sometimes-conflicting sources (1990/1995/2005/2010) into one honest narrative. |
| Hands-on/application potential | One concrete activity ("Name It to Tame It") with a real, falsifiable prediction step. |
| Implementation/economic value | Not economically quantifiable (no purchase/build involved); value is behavioral, not financial. |
| Repeat-use value | Moderate — the technique is reusable indefinitely, but the lesson itself is a single read, not a repeat-visit product on its own. |
| Visual explanation need | Two visuals genuinely earn their place: the four-abilities structure, and the reappraisal-vs-suppression outcome comparison (both specified in `visual-production-brief.md`, neither produced yet). |
| Free-resource opportunity | Strong fit — see Mission/Free/Paid strategy above. |
| Paid-depth opportunity | Not for this piece; noted as a future bundle candidate only. |
| Bundle/next-learning opportunity | Real, future-facing: pairs naturally with "Difficult Conversations" or "Reading a Room" if those get developed later. |
| Production complexity | Low: no interactivity, no calculations, no branching logic — a single-page guide plus one worksheet. |
| Evidence confidence | High for the core definition (3 corroborating sources); appropriately moderate/disclosed for the "does it matter" question (deliberately unresolved in the field, and the product says so). |

## Recommendation
**Proceed to Product Design at Free / Focused-scope tier.** The gap is real, the evidence is sufficient for the claims actually being made, and the production cost is low. Do not expand scope into an assessment tool, multi-lesson course, or clinical-adjacent content — none of that is supported by the approved research depth.
