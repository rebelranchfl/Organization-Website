# Context Review — RRA-2026-0004

## Project
**Containers Are Containers — Safe Storage by Function**

## Why this exists
This project is a spin-off from `RRA-2026-0001 — Water Through the Layers`, created from the structured opportunity `safe-water-storage` (score 89/100, recommendation `PURSUE_NOW`). It solves the next problem after treatment: keeping water fit for its intended use after collection or treatment.

## Governing context reviewed
- Repository working rules and ecosystem boundaries.
- RRA concept/direction and Program Hub source.
- Academy content workflow, project schema, source-review policy, revision-preservation rule, product-phase extension, Think Like a Rebel framework, Responsible Rebellion/Evidence-First standard, and Late-Finding Control standard.
- Current RRM and Academy public sites were requested through live web fetch; direct crawler access was unavailable in this run, so the current GitHub Academy source and governing public-site records were used rather than assuming live copy.

## Learning area
`Sustainability & Agriculture`

Storage is a system function, not merely a container-purchase topic. It connects safe household water, emergency resilience, livestock care, agricultural water, maintenance, inventory rotation and capacity planning.

## Likely audiences
- rural households and private-well families;
- homesteaders;
- families building emergency water reserves;
- livestock keepers;
- small growers;
- homeschool families learning practical systems thinking.

## Boundary from the parent Water product
This project does not reopen or rewrite Water Through the Layers. It narrows one branch into a standalone research foundation: what safe storage must accomplish, how the answer changes by intended use, and how to evaluate existing/reused/purchased containers by function and risk.
