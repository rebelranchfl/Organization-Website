# RRA-2026-0001 — My Water Plan Specification

**Status:** PRODUCT WORKING — REQUIRED PAID OUTPUT  
**Purpose:** Define the tangible personalized result the learner receives from Build Your Water System.

## Value rule

My Water Plan must show actual work RRA did with the learner's input. It may not be a generic paragraph summary.

## Whole-system view

At the top show:
- source;
- selected uses;
- shared infrastructure;
- branch map;
- current testing/knowledge status.

Example structure:

`PRIVATE WELL`

`shared source / pump / first-stage protection`

`↙ DRINK & COOK   ↓ ANIMALS   ↘ IRRIGATION`

The learner can expand each branch without losing the whole-system view.

## Per-branch plan

Each selected branch contains:
1. **What this branch needs to do** — required functions;
2. **What we know** — learner-specific facts/results;
3. **What is still unknown** — only unknowns that matter to the branch;
4. **What testing would change** — name the decision, not just the test;
5. **System options** — DIY / purchased / hybrid where approved evidence supports them;
6. **What each part does** — component/layer function;
7. **Use what you have** — suitable existing resources;
8. **Source locally / reuse** — viable substitutions;
9. **Worth buying** — where validated performance, durability, accuracy or other approved reason justifies purchase;
10. **Do not substitute** — only where the approved evidence establishes a material boundary;
11. **How to verify**;
12. **Maintenance / retest**;
13. **Failure / backup**;
14. **Next action**.

## Tangible build/system references

Where relevant the branch links to in-product diagrams/build concepts such as:
- 55-gallon layered filtration system;
- 5-gallon gravity system;
- settling/prefiltration/storage system;
- well/pump/storage/branch system;
- validated UV treatment train;
- animal watering distribution/automation;
- irrigation/storage/delivery branch;
- modern contaminant-specific treatment examples.

Every reference says what the system does and what it does not establish.

## Testing behavior

Testing does not blank the plan.

Before testing, the plan can still show:
- source/use structure;
- general treatment functions;
- applicable system families;
- storage/movement/control concepts;
- resource/substitution options;
- what the missing test would decide.

After a relevant test/result category is entered, dependent treatment/verification choices update.

## Responsible Rebellion comparison record

If the learner runs an experiment/comparison, My Water Plan stores:
- system compared;
- what was changed;
- before observation/result;
- after observation/result;
- test/verification result category;
- cost/consumables notes where entered;
- maintenance/effort notes;
- what worked;
- what did not;
- what the learner will change next.

Permanent display rule: **A successful build is not proof. Test the result.**

## Next three actions

The plan ends with three concrete actions generated from the learner's current state, such as:
- inspect/confirm a source fact;
- obtain a specific category of test because it changes a named decision;
- build/compare a supported prefilter/storage branch;
- choose between two functionally appropriate options;
- verify/maintain an existing system.

Actions must be specific to the saved branch state, not generic `learn more` prompts.

## State and export

The active product session must preserve the plan through normal navigation and optional-depth exploration. A printable/exportable plan may be offered if included in the approved implementation, but the plan must first work as a living in-product result.

## Paid-value test

This output passes paid-value QA only if a learner can look at it and answer:
- What system am I actually building/using?
- Why are there multiple branches?
- What does each branch need to accomplish?
- What can I use that I already have?
- What should I buy only because the function justifies it?
- What do I still need to test?
- What will that test change?
- How will I know my system worked?
- What do I do next?

If those answers are not visible, My Water Plan is not complete.
