# Rebel Ranch Local — Launch Visual Asset Index

This folder is the visual-production index for the August 2026 Rebel Ranch Local launch. Every graphic should have a defined purpose, audience, and CTA so the campaign does not become repetitive.

## Assets currently stored in the repo

### `reel-02-problem.jpg`
**Scenario:** Problem / recognition  
**Audience:** buyers, sellers, service providers, local community  
**Purpose:** make people recognize the problem before introducing the solution.  
**Core message:** Facebook posts disappear, local vendors are hard to find again, local services are scattered, and big business gets most of the attention.  
**Primary CTA:** Comment if this has happened to you.  
**Reel role:** early launch / awareness / problem recognition.  
**Notes:** Use **Rebel Ranch Ministries** when the organization is named in supporting copy. Do not shorten the organization name to `Rebel Ranch`.

## Production rules

- Reel graphics are individual vertical visual beats intended to be assembled into video.
- Do not repeat the same headline, benefits, or CTA across every reel.
- One reel should have one main job.
- Use realistic imagery and the approved Rebel Ranch Local brand system.
- Use real website/app screenshots whenever the reel is explaining actual product use.
- Keep copy readable in roughly 1–2 seconds on a phone.
- Keep the master logo consistent; do not independently regenerate logo variants with changed geometry, fonts, icons, or imagery.
