## What the market shows

### 1. Information itself is cheap or free

The learner can find substantial government/Extension guidance at no charge and low-cost static guides starting under $10.

Therefore RRA should **not** justify $39 simply by claiming to contain a lot of water facts.

### 2. $39 is defensible only if the interactive/product-system value is real

The RRA value case is:

- decision sequencing instead of generic information;
- one Water Profile that removes irrelevant branches;
- source + intended-use separation;
- testing-first routing;
- treatment job rather than product-name logic;
- function-before-form resource planning;
- build / buy / reuse comparison;
- storage/distribution/automation integration;
- UV and other disinfection options kept inside their evidence boundaries;
- personalized system block diagrams;
- verification / maintenance plan;
- transferable Think Like a Rebel systems method.

If those interactive and implementation components are not produced, $39 becomes harder to defend against the $18–$45 static-guide market.

### 3. RRA should not compete with free UF/IFAS material by duplicating it

The free **Know Your Water** layer should complement the public-information environment by compressing the learner's first decisions into an easier path, not by paywalling basic well-safety information already available free.

The paid layer should begin where free guidance usually stops: **personalized narrowing, function mapping, resource inventory, build/buy planning, system architecture, maintenance, and transfer learning.**

If the delivered product is reduced to a static text PDF, the current market evidence supports reconsidering a lower price rather than pretending interactive value exists.

## Major scope differences versus comparables

RRA does **not** win by having more pages.

RRA's intended differentiation is the combination:

`SOURCE + USE → KNOWNS / UNKNOWNS → TEST → TREATMENT JOB → FUNCTIONAL DECOMPOSITION → RESOURCES → SAFE SUBSTITUTIONS → BUILD / BUY → VERIFY → MAINTAIN → NEXT LEARNING PATH`

The competing guides reviewed generally teach water/testing/treatment information. RRA's proposed paid value is a reusable **decision-and-system-design method** around that information.
