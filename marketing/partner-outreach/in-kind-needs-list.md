# Rebel Ranch Ministries In-Kind Donation Needs List

## Purpose

A running, prioritized wishlist of physical items and equipment Rebel
Ranch could use as in-kind donations — feeds the "what we need" side of
`partner-rules.md`'s mutual-exchange asks (see Category B entries in
`outreach-queue.md`).

Managed from the marketing dashboard (`marketing/dashboard.html`) —
check items off as fulfilled, set priority, and add new items as they
come to mind. Each item's `Source` field is a starting guess at which
researched business/category (see `local-landscape.md`) would be the
natural donor — not a commitment, just a pointer for drafting outreach.

Format for the dashboard to read/write:
`- [ ] Item Name :: Priority: High/Medium/Low/Unset :: Source: text :: Notes: text`
Check the box (`[x]`) once an item is fulfilled/received.
