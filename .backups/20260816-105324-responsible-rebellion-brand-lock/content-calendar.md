# Rebel Ranch Ministries Social Media Content Calendar

## Purpose

This calendar tells the Rebel Ranch marketing agent what type of content to create, when to create it, and what each post should point back to.

The agent must follow `brand-rules.md` before writing, designing, scheduling, or posting anything.

Brooke only approves, rejects, or corrects content. The agent creates the content, maintains this calendar and the working queue, checks supporting records, and performs all other automatable steps.

`draft-posts.md` is the only working queue. Do not create or use `approved-posts.md` or another duplicate tracker.

## Posting History Rule

Before creating, scheduling, or posting new content, the agent must check `posted-archive.md`.

The agent must avoid:

- repeating the same exact post
- overusing one content bucket
- posting donation asks too close together
- reposting the same topic into multiple groups without changing the wording
- ignoring prior engagement or follow-up notes

`posted-archive.md` is the source of truth for what has already gone live.

## Weekly Minimum

The agent should create and place in `draft-posts.md` at least:

- 3 Rebel Ranch page posts
- 2 Facebook group post options
- 1 donation/support post
- 1 community engagement post
- 1 behind-the-scenes/farm update
- 1 program-focused post

---

## Approval Rule

No post moves from draft to approved unless it passes the checklist in `brand-rules.md`.

Brooke's approval, rejection, or correction is recorded on the original entry in `draft-posts.md`; the agent does not move approved content into another file.

Approval does not authorize posting by itself. The agent may schedule or post only when that action has also been separately authorized.

No group post is used until the agent has reviewed the group's About section, Rules section, Featured posts, pinned posts, and admin guidance through available browser access and updated `group-rules.md`. If the review cannot be completed, the group remains `Needs review` and is not used.
