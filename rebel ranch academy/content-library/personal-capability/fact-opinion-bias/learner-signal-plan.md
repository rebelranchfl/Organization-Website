# RRA-2026-0003 — Learner Signal Plan

**AI-Agent:** ChatGPT/GPT-5.6 Sol  
**Session:** RRA Product Design Agent

Collect only structured product-learning signals useful for improving the experience. Do not collect names, emails, addresses, unrestricted personal narratives, IP addresses or browser fingerprints as learner intelligence.

## Useful signals

- entry mode: free sorter / full workflow;
- scenario domain selected;
- prebuilt vs learner-entered claim;
- number of claim layers identified;
- claim-layer types selected;
- number of evidence/source items added;
- source-independence state distribution;
- whether Trace the Echo was completed;
- whether contrary evidence was entered;
- whether learner completed both sides of Bias Mirror;
- social-pressure pathways selected (information/belonging/norm/value weighting/none/unknown);
- public/private gap selected when relevant;
- confidence state before and after stress test where intentionally measured;
- cost-of-error category;
- next-action category;
- depth controls opened: why/research/technical/sources/example;
- activity selected/completed;
- Decision Record completed/updated;
- transfer challenge completed;
- abandonment step;
- format preference if offered (interactive/print/reference).

## Product questions these signals answer

- Which domains actually drive use: family, social, money, business, community?
- Do learners struggle more with claim classification or evidence independence?
- Does the social-pressure layer change confidence/next action?
- Are technical/evidence depth controls used or ignored?
- Which activities create repeat engagement?
- Do learners return to update a Decision Record?
- Is the free sorter a meaningful entry into deeper work or sufficient by itself?

## Privacy/minor boundary

Use random session/product keys when grouping is necessary. Account association requires a legitimate separately approved feature. For minors, preserve parent/guardian controls and do not use free-text collection to capture sensitive personal conflict stories.

Public analytics disclosure remains a later release gate.
