# RRA-2026-0007 — Research QA

Status: PASS  
Date: 2026-08-23  
Agent: RRA Research/Content Agent

## Evidence QA

- [x] Research does not begin from `rainwater is safe` or `rainwater is unsafe`; it separates intended use, system design and evidence.
- [x] Potable-use claims are corroborated across CDC, WHO and peer-reviewed research.
- [x] Historical/traditional practices are identified as documented practice, not automatic proof of modern safety.
- [x] First-flush evidence is taught without inventing a universal diversion volume.
- [x] Roof/catchment material differences and chemical/microbial risks are visible.
- [x] Testing is framed as verification/refinement, not a blanket gate on system education.
- [x] Source-by-source owner approval is not treated as required.

## Responsible Rebellion QA

- [x] Evidence determines what RRA may teach.
- [x] Learner-specific unknowns change personalization, not whether rainwater-system functions can be taught.
- [x] Government/institutional sources are evidence, not automatic supremacy.
- [x] Credible historical, regional, scientific, engineering and field systems were deliberately compared.
- [x] Modernization gains and created dependencies are both addressed.
- [x] `Teach transferable principles, not isolated facts.` is preserved.
- [x] `TRANSFER THE PRINCIPLE` is present and identifies where analogy stops.

## Tangible-output QA

- [x] catchment → conveyance → first flush/prefilter → tank → overflow → delivery → treatment/use branch;
- [x] component function and maintenance;
- [x] historical/regional variants;
- [x] low-resource barrel through larger modern cistern/treatment paths;
- [x] roof-yield calculation;
- [x] storage-demand water balance;
- [x] multiple simultaneous intended uses;
- [x] substitutions/use-what-you-have evaluation;
- [x] test/verify plan.

## Safety QA

Specific material hazards identified without generic disclaimer clutter:

- confined-space tank entry;
- structural load;
- cross-connection;
- mosquito/insect access;
- unsuitable catchment materials for potable use;
- clear-looking water not proving safety.

No unnecessarily hazardous DIY treatment recipe was invented.
