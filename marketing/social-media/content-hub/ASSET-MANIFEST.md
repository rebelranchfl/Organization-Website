## Asset-handling rule

For every new visual created from this point forward, record all of the following before moving to the next batch:

- permanent asset ID;
- program and campaign;
- title / scenario;
- purpose;
- audience;
- primary message;
- primary CTA;
- post caption/context;
- reel role and frame order if applicable;
- high-resolution master filename;
- external master archive destination;
- repository preview filename;
- status: Planned / Visual Ready / Needs Review / Approved / Posted.
