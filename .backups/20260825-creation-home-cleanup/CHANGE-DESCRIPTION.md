# Creation Station homepage cleanup — intended change

Date: 2026-08-25
Target: `creation.html` only

Owner-approved direction:
- streamline the existing Creation Station public marketing experience rather than add more content or features;
- preserve the approved Creation Station colors, styling, Studio preview, Marketplace card, header/footer identity, and existing application surfaces;
- market the complete Creation Station value to parents and creators, not merely arts-and-crafts activity or productive screen time;
- make parent value prominent: time back, less activity-management burden, better use of screens, lasting value from money already spent on creative supplies, and the possibility (never guarantee) of recovering some material costs;
- show the creator-development path: creative interest → finished work → documentation/portfolio → business and money skills → optional public Studio → possible earning opportunity → greater independence/self-sufficiency;
- preserve and strengthen the creative-belonging/Club value: moderated social space for young creators to make, talk, share, collaborate, and spend time with peers who understand their interests;
- distinguish Creation Station Studio (paid standalone creator landing page) from Rebel Ranch Marketplace (separate free local-discovery program/application);
- keep Creation Station in beta and invite real-family feedback without presenting the product as unfinished or unbuilt;
- avoid wording that blurs Creation Station into future trades/vocational education. Terms such as making, projects, and skills must remain anchored in art, crafts, creative hobbies, presentation, and creative entrepreneurship.

Implementation boundary:
- No CSS or visual-system redesign.
- No dashboard, membership, Club, Studio, Marketplace, database, payment, authentication, or backend changes.
- No new page creation.
- Preserve existing functional destinations unless copy changes require clearer labels.
